| Nazwa zmiennej | Opis |
| --- | --- |
| _wt_SysMatJoinType=1 | Sposób łączenia blatów:<br/>0 - bez zacięcia<br/>1 - zacięcie z zaokrągleniem<br/>![Łączenie z zacięciem i zaokrągleniem](/img/zmienne-join-z-zacieciem.png)<br/>![Łączenie bez zacięcia](/img/zmienne-join-bez-zaciecia.png)<br/>Z opcją _wt_SysMatJoinType=1 powiązany jest również parametr _wt_SysDefOptInc=20 oraz _wt_SysDefExtOptInc=5.<br/>Parametr _wt_SysDefOptIncExt umożliwia dodatkowe zwiędszenie długości blatu do optymalizacji przy łączeniu poprzez zacięcie (np. dodatkowy nadmiar po d frezowanie w celu wyrównania krawędzi). W konfiguratorze nadmiar ten dodawany jest dla każdej krawędzi, która jest poddana obróbce do złącza.<br/>Długość blatu do rozkroju jest zatem liczona wg wzoru:<br/>L = Lz + _wt_SysDefOptInc * 2 + _wt_SysDefExtOptInc * 2<br/>gdzie<br/>Lz - zdefiniowana długość blatu<br/>(przy założeniu, że jest z obu stron obrabiany do łączenia) |
| _wt_SysDefOptInc=20 | Wartość zwiększenia wymiaru związanego z zacięciem. |
| Przykładowe parametry dla blatu i powiązanych złącz. | Zmienne dla blatu:<br/>_wt_SysDefOptInc=20<br/>_wt_SysDefOptIncExt=0<br/>_SYS_MAT_JOIN_TYPE=1<br/>_SYS_MAT_DISABLE_EDGES=0 |
| _wt_SysMatEdgeOrgR1=8<br/>_wt_SysMatEdgeOrgR2=6 | Zmienne określające promień zaokrąglenia.<br/>- …OrgR1<br/>- …OrgR2<br/>![Promień zaokrąglenia OrgR1 i OrgR2](/img/zmienne-promien-zaokraglenia.png) |
| _SysDefEdgeTrimInc | Zmienna określająca wartość odcięcia w przypadku krawędzi fabrycznej i zastosowania oklejania tej krawędzi okleiną.<br/>Wymiar formatki do optymalizacji jest zwiększany defacto o wartość odcięcia. Dlatego w przypadku wymaganego wymiaru np. pełnej szerokości blatu 600mm system będzie potrzebował blatu szerszego, gdyż wymiar zostanie zwiększony do optymalizacji do, np. 625mm lub należy zmniejszyć żądany wymiar do np. 575mm.<br/>![Wartość odcięcia krawędzi fabrycznej](/img/zmienne-odciecie-krawedzi-fabrycznej.png) |
| _SYS_MAT_JOIN_TYPE=1<br/>_SYS_MAT_DISABLE_EDGES=0<br/>DEFAULT:WT_MAT_JOIN_TYPE_EDIT=1<br/>WT_JOIN_TYPE=$FORCE_HIDE$ |   |
| WT_EDGES_FRONT_TYPE=[0/1]<br/>Powiązanie zmienne:<br/>_wt_SysMatJoinType<br/>wt_EdgesFrontType<br/>wtL_LengthInc<br/>wtT_LLengthInc<br/>wtT_RLengthInc<br/>wtR_LengthInc | Oklejanie przedniej krawędzi. Jeżeli ta opcja jest ustawiona to w przypadku krawędzi zaokrąglonych system automatycznie uwzględnia wymiar odcięcia zaoblenia zdefiniowany w parametrach zasobu “Docięcie zaokrąglonej krawędzi”. |
| DefinedVariables<br/>Zestaw zmiennych ustawionych indywidualnie:<br/>_wt_SysDefOptInc=25 | Zmienne rozdzielane znakiem średnika w przypadku zapytań SQL!<br/>Zmienne DefinedVariables nadpisują wartości zmiennych zdefiniowanych w StandardVariables! |
| StandardVariables<br/>Zestaw zmiennych:<br/>_wt_SysDefOptInc=20;<br/>_SYS_MAT_JOIN_TYPE=1;<br/>_SYS_MAT_DISABLE_EDGES=1 | Domyślne wartości zmiennych przypisanych zasobowi (blatowi).<br/>Każdy blat powinien mieć zdefiniowany zbiór (Set) zmiennych, które ustawiają pracę konfiguratora z uwzględnieniem wartości domyślnych, tak aby po wybraniu materiału, np. na blat HPL konfigurator ustawił odpowiednio wszystkie parametry. |
