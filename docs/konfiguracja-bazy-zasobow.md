Konfigurator FastCube3D (FC3D) działa w oparciu o bazę danych MySQL systemu FastCut (FC) oraz Order Manager (OM). Z bazy danych (tabela Materials) pobierane są podstawowe informacje niezbędne do prawidłowego działania systemu. W celu zapewniania prawidłowej pracy należy uzupełnić podstawowe dane zgodnie z poniższym opisem.
